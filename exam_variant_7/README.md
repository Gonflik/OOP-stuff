## Варіант 7 — Агент фітнес-тренера

### OOP-завдання
Реалізуйте систему обліку тренувань:

1. Абстрактний клас `Exercise` з атрибутами `name`, `duration_min: int` та абстрактним методом `calories_burned() -> float`.
2. Класи `CardioExercise` та `StrengthExercise` що успадковують `Exercise` та реалізують `calories_burned()`:
   - `CardioExercise` має коефіцієнт `intensity` (1.0–2.0), формула: `duration_min * 8 * intensity`
   - `StrengthExercise` має `weight_kg: float`, формула: `duration_min * 5 + weight_kg * 0.5`
3. Клас `Workout` що:
   - зберігає список вправ (`__exercises` — приватний, інкапсуляція)
   - методи `add(exercise)` та `total_calories() -> float` (поліморфізм через `calories_burned()`)
   - метод `summary() -> dict` — повертає `{"exercises": [...], "total_calories": ...}`

### AI-агент
- **Інструмент (tool):** функція `calculate_workout(exercises: list) -> dict` — **всередині функції** створює об'єкт `Workout`, для кожного елементу зі списку (словник з полями `type`, `name`, `duration_min` та `intensity`/`weight_kg`) створює відповідний об'єкт `CardioExercise` або `StrengthExercise` і додає через `add()`, потім викликає `summary()` та повертає результат.
- **Промпт агента:** агент є персональним фітнес-тренером. Він розраховує калорії для тренувань та дає рекомендації щодо навантаження. Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 запитання з різними наборами вправ.
